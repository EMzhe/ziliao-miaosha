## 第一部分：科学蒙题绝学

### 蒙题总纲
蒙题≠瞎蒙，是在20秒内利用出题规律、选项结构、常识约束把正确率从25%提到60%+的决策科学。**蒙完必须标注"此为概率判断"，并给出验证路径。**

### 蒙1：选项结构蒙题
- **区间选项**（不到X / X~Y / 超过Y）：优先验证中间区间（出题人爱把正确答案放中间，且"不到/超过"两端验伪成本高）。
- **数值选项**：正确答案常不是最整、也不是最离谱的；三个数量级一致一个不一致 → 排除不一致的（量级坑）。
- **排序选项**：先看首尾（最大/最小）排除，中间通常只剩一个。
- **"多/少"成对选项**（A.多1083 B.少1083 C.多1216 D.少1216）：先判正负砍掉一半，再比较数值——数值常等于现期差或估算差，两步定答案（以坑治坑）。

### 蒙2：出题人惯性蒙题
- 现期差常作基期和差题的干扰项 → 排除。
- 增长率 r 与比重差 |a-b| 常互为干扰：两期比重差的正确答案**必小于|a-b|**。
- 平均数增长率答案常比 (a-b) 略小（除以1+b压缩）。
- 间隔增长率 r间 > r₁+r₂（同号时）；一正一负时 r间 < r₁+r₂。
- 综合分析"能够推出"：CD优先，简单判断项（口诀类、现期类）优先。

### 蒙3：材料常识蒙题
- GDP、人口、收入类：全国数据增长为常态（3%~10%），下降必是特殊年份（如2020疫情、2022房地产）。
- "占……比重"：部分/总体，答案一般在5%~60%之间，出现>100%基本是量级错了。
- 平均数问题：答案应介于该组数据的最小值与最大值之间——瞪选项可直接排除越界项。
- 倍数问题："是几倍"≥1，"多/增长几倍"=是几倍-1 可为0~1的小数。

### 蒙4：量级与首数蒙题
- 算不了精确值时，先定**量级**（10的几次方）和**首位**，选项中首位不同 → 首位定生死（截位直除截两位的底层逻辑）。
- 遇到"约、左右、接近"：正确答案离边界通常有一段安全距离；刚好压线的往往是干扰项。

### 蒙5：验证兜底原则
AI解题时的独有优势：**蒙题结论必须过一遍 Python 精确计算（calc_verify.py）**，机器验证通过才输出。蒙题只用于给人类考生的"考场思维"教学，不用于最终答案。

## 第二部分：选项陷阱全录

### 陷阱1：时间坑
- 问题问"2019年"材料给"2020年比2019年增长" → 求基期不是现期。
- "十三五（2016-2020）"5年还是求"2016-2020年间隔"4个年份差：年均增长量=(现期-基期)/5，年均增长率开5次方。
- "1-6月"与"二季度"：Q2=1-6月减Q1。
- "截至X年末"与"X年全年"。
- **年均增长率年份差n**：2018-2022 → n=4（基期是2018，间隔4年增长4次）；"2016年初到2020年末"→n=5。易错率极高！

### 陷阱2：单位坑
- 千公顷vs公顷、万吨vs吨、亿美元vs万美元、千瓦vs万千瓦vs亿千瓦。
- "人均月收入"vs"人均年收入"（×12或÷12）。
- 选项把单位换算错一位设坑（如正确5.4万亿，干扰项0.54万亿/54万亿）。

### 陷阱3：主体坑
- "其中"嵌套：房地产=房产+地产，问房产时别用房地产整体增速。
- 主体换名："规模以上工业新能源汽车"≠"新能源汽车"（口径不同）。
- "全国"vs"全省"vs"全市"；"进口"vs"进出口"；"出口额"vs"出口量"。

### 陷阱4：概念坑
- 增长率vs增长量：r是%，增长量是具体值。
- 百分点vs百分数：增速提高5个百分点=+5pp，不是×5%。
- "同比"vs"环比"：同比对去年同期，环比对上一期。
- "顺差"=出口-进口；"逆差"=进口-出口。
- "是几倍"vs"多几倍/增长几倍"：多几倍=是几倍-1。
- "降幅"vs"增长率"：下降8%的降幅扩大→更负；降幅收窄→回升。

### 陷阱5：范围坑
- "占"的分子分母口径：A占B的比重=A/B，别反。
- 部分占比总和应为100%（饼图验算）。
- 比重变化问"个百分点"却给"%"的选项。
- 平均数"每"字后面是分母：人均GDP=GDP/人（后÷前）；"平均每场次服务人次"=人次/场次。

### 陷阱6：图表坑
- 饼图12点起顺时针对应主体顺序（绝技25+）。
- 柱状图纵轴不从0开始 → 高度差≠实际差。
- 双纵轴图：左右轴单位不同。
- 折线图斜率=增速：斜率大不代表增速大（基期不同），瞪眼需转"高度差/柱高"。

### 陷阱7：综合分析坑
- "能够推出"vs"不能推出"（审题第一件事）。
- 正确项常需要2-3步验证，错误项常一步即可证伪 → 先证伪简单的。
- "年均增量（以2011年为基期）"→n的取法又见陷阱1。
- 选项中"高于/低于上年"：用两期口诀（a vs b）秒判，别硬算。
