# 资料分析36绝技完整手册

> 基于公考瞪哥《资料分析36绝技》（2026版），融合花生十三、齐麟、李委明、粉笔、华图、中公等主流名师/机构公开速算方法论。
> 按题型模块组织，路由到本手册后只读对应章节。

## 模块一：速算技巧（绝技1-9，全题型通用）

### 绝技1-高位叠加
- **场景**：多个数加和（求总额、总量题）。
- **操作**：从高位开始加，层层错位相加，尽量口算。
- **示例**：683+236 → 6+2=8（百位），8+3=11（十位，写1进1），→ 919。3647+3919+4196+4330 → 万位0+1+1+1=3千位…先加高位定范围（如首两位：36+39+41+43=159→约1.59万）。
- **真题**（2024国考）2017~2022年全国移动数据流量业务收入总额范围？→ 各年首两位相加定位区间，选"不到3.4万亿"类区间选项。
- **融合**：与"削峰填谷"（绝技27）配合，凑整基准值再高位叠加更快。

### 绝技2-划线减法
- **场景**：减法速算（求差、增量、比较大小）。
- **操作**：
  1. 整数基准值划线：532-489 → 532-500+11=43。
  2. "12"或"21"划线：624-351 → 62-35=27，273。
- **真题**（2024黑龙江）2022年四个季度全国居民人均工资性收入最高的是？→ 累计值划线减法求当季值。

### 绝技3-化乘为加法
- **场景**：任意两位数乘法。
- **口诀**：前前后后，里里外外。16×14：前×前=1，外×外=4，内×内=24 → 十位交叉相加。
- **融合（李委明错位相加）**：×1.1=错位相加，×0.9=错位相减（见绝技8）。

### 绝技4-百化分转化法
- **场景**：增长率/比重与分数互化，一切含%的计算。
- **操作**：将 r 转为 1/n：1/2=50%，1/3≈33.3%，1/4=25%，1/5=20%，1/6≈16.7%，1/7≈14.3%，1/8=12.5%，1/9≈11.1%，1/10=10%，1/11≈9.1%，1/12≈8.3%，1/13≈7.7%，1/14≈7.1%，1/15≈6.7%，1/16=6.25%，1/17≈5.9%，1/18≈5.6%，1/19≈5.3%，1/20=5%。
- **真题**（2022国考）2019年中国IC先进封装市场规模？→ r≈百化分后乘除互转秒出。
- **融合（花生十三415份数法）**：把基期看成n份，增长量=r份，现期=(n+r)份（如r=1/4时，基期4份、增量1份、现期5份），直接按份秒杀。

### 绝技5-截位直除法（除法之王）
- **场景**：除法通用（一切除法题的首选）。
- **操作**：
  1. **怎么截**：从左往右第一个非0数字起，截几位就四舍五入保留前几位。
  2. **截谁**：一步除法只截分母；多步计算分子分母都截。
  3. **截几位**：看选项——首位均不同，或首位有相同但次位差＞首位 → **截两位**；首位相同且次位差≤首位 → **截三位**。
- **示例**：3732/20167 → 截两位：37/20≈1.86 → 18.5%（选B）。
- **融合（齐麟截位直除体系）**：选项是区间（如"不到3.4万亿"）→ 可大胆截两位；选项是具体值且接近 → 截三位保精度。

### 绝技6-拆分法
- **场景A 除法拆分**：分子在分母50%附近先拆50%；接近1先拆100%；分子小拆10%/5%/1%。
- **示例**：47598/89894 ≈ 50%+？→ 89894×0.5=44947，47598-44947=2651≈3% → 53%。
- **场景B 乘法拆分**：45%=50%-5%，55%=50%+5%，15%=10%+5%，95%=1-5%，392×48%=392×50%-392×2%=196-7.84≈188。
- **融合（花生十三假设分配法）**：如 89894 增长5.3% → 假设基期8.5万份+增量份额，逐步逼出精确值，适合增长量计算。

### 绝技7-错位修正法
- **场景**：除法，分子分母接近或有倍数关系时。
- **原理**：分子分母等比例加减，分数大小不变。
- **操作**：错开相同位，加减相同倍（看分母1%或1/n的倍数）。
- **示例**：77/181 → 分母181接近154(=77×2)×…，修正成 77×2.3/181×2.3≈…→ 42.5%~43.6%区间精算。
- **融合（李委明放缩法）**：分子分母同乘小数字化整，本质相同。

### 绝技8-特殊数字瞪眼法
- **口诀**：×1.5=本身+半；×1.1=错位相加；×0.9=错位相减。
- **拓展**：×5=×10÷2；×25=÷4；×125=÷8；÷5=×2÷10；增长率>10%判断用"错位相加"（现期×0.1与增量比），降幅>10%用"错位相减"。
- **真题**（2017联考）按2016年1-6月同比增速推算2017年城镇消费品零售额 → 134249×1.102=134249+13424（错位相加）≈147673 → 选C。

### 绝技9-分数比较口诀法（比较之王）
- **场景**：任意分数/增长率/比重比较大小。
- **口诀**：
  1. **一大一小**：分子大的分数大（钱多人少）。
  2. **同大同小**：竖着直接除比商；横着比倍数，谁的倍数大听谁的（分子倍数>分母倍数→该分数大）。
- **示例**：比较73.0/4061.8与62.5/4234.9 → 分子大分母小（一大一小）→ 前者大。
- **融合（瞪哥"瞪眼法"+花生十三"差分法"）**：分数接近时，用差分数（大分子-小分子/大分母-小分母）与小分数比较，差分数大→大分数大。

## 模块二：基期量（绝技10-11）

**审题**：问题时间在材料时间**之前**，求具体量。
**公式**：①基期=现期-增长量；②基期=现期/(1+r)；③基期=增长量/r。

### 绝技10-除法技巧巧用瞪眼法
- **适用**：|r|>5%时。
- **工具箱**：截位直除（首选）、错位修正、百化分、拆分、分数比较。
- **示例**（2025内蒙）：2023年末面积5631.6万㎡，同比增长7.8%，求2022年末 → 5631.6/1.078 → 截两位：56/11≈5.1 → 5100万㎡级，选B（5100~5200）。
- **真题**（2021四川）2015年黄河流域棉花单产：增长率数据较多时理清"产量/面积"，(534.3-26.0-10.0)…分步用划线减法+拆分。

### 绝技11-化除为乘瞪眼法
- **适用**：|r|≤5%（r很小时近似误差可忽略）。
- **公式**：A/(1+r) ≈ A×(1-r)；A/(1-r) ≈ A×(1+r)。
- **示例**（2024黑龙江）：2022年住宿餐饮增加值17855亿元，同比下降2.3%，求2021年 → 17855×1.023≈17855+17855×2.3%≈17855+411≈18266 → 选B（18275）。
- **融合（粉笔"增长率化除为乘"）**：r绝对值≤5%专用，超过5%误差放大，必须回退绝技10。

## 模块三：基期和差（绝技12-14）

**公式**：基期和差 = A/(1+a) ± B/(1+b)。

### 绝技12-以坑治坑法（首选秒杀）
- **适用**：选项有正负（多/少）、有相同数值选项。
- **操作**：①判正负（估算A/(1+a)与B/(1+b)谁大）；②排现期（正确答案≠现期差，出题人常把现期差设为干扰项）。
- **真题**（2023重庆）2020年农村 vs 城镇居民经营性收入 → 先判多少定正负，再排除现期差干扰项。

### 绝技13-转化思维法
- **适用**：好算增长量时（r可百化分）。
- **操作**：先算增长量 △A=A×a/(1+a)、△B=B×b/(1+b)，则基期和差=(A±B)-(△A±△B)。
- **真题**（2024河南）2022年文化批发零售+文化服务业收入 → (20814+67739)-两个增长量 → 混合可再用绝技20。

### 绝技14-混合思维法
- **适用**：A远大于B时（部分远大于另一部分）。
- **操作**：基期差=(A-B)/(1+r)，其中r取大者的增长率（B占比小影响弱）。
- **真题**（2023四川）2021年1-6月全社会用电量 → 1-7月减7月：(49303-8324)/(1+3.4%)。

## 模块四：现期量（绝技15-16+）

**审题**：问题时间在材料时间**之后或相同**，求具体量。
**公式**：①现期=基期+增长量；②现期=基期×(1+r)。

### 绝技15-拆分法
- **适用**：(1+r)不好算时。
- **操作**：拆分出好算的数字。3721×1.068=3721+3721×0.068 → 3721×0.07≈260-7≈…≈3974 → 选C。
- **融合（华图特征数字法）**：r接近1/n时，直接用1/n替代（r=6.8%≈1/14.7≈…尽量找接近的百化分）。

### 绝技16-选项代入验证法
- **适用**：求年份差n（"哪一年首次超过X"）。
- **操作**：从中间选项代入验证，排除。Z省律师业务150万件 → 假设2027年：现期+2×年均增量 vs 150万，不足则往后，超过则往前。
- **真题**（2025江苏）新能源汽车产量突破3000万辆的年份 → 1316.8×(1.394)ⁿ≥3000 → n=2时代入验证。

### 绝技16+-等比数列法
- **适用**：未给增长率，保持增长率不变/按平均增速推算。
- **操作**：①按增量估算 < 按增长率计算（增量法低估）；②错位修正。
- **公式**：aₙ=a₁×qⁿ。
- **真题**（2023河北）2018-2022平均增速推2027年 → 先求总增速再开5次方，结合幂次方表（绝技21工具）。

## 模块五：增长率（绝技17-21）

**公式**：r=增长量/基期=增长量/(现期-增长量)=现期/基期-1；"高减低加"（已知百分数和百分点）。

### 绝技17-除法技巧巧用瞪眼法
- **工具**：截位直除、百化分、错位修正。
- **增速>10%判断**：错位相加（现期×0.1 与 增量比较）。
- **降幅>10%判断**：错位相减。
- **增速>20%判断**：拆分法（现期×0.2）。
- **真题**（2024黑龙江）蜂窝物联网终端用户增速：4.47/(18.45-4.47)=4.47/13.98→ 截两位45/14≈32% → 选C。

### 绝技18-分数比较瞪眼法（增速比较）
- **柱状图瞪眼**：高度差大且柱子矮 → 增速大（增长量/基期）。
- **特殊数字1.1/1.2**：现期/基期 与 1.1（或1.2）比较判断增速是否超过10%/20%。
- **真题**（2025四川）平均每万人设施建筑面积增速最快的年份 → 竖直瞪柱子高度差。

### 绝技19-比心公式巧用法（间隔增长率）★高频
- **公式**：r间=r₁+r₂+r₁×r₂（"和+积"）。
- **逆向**：已知r间和r₁，求r₂=(r间-r₁)/(1+r₁)。
- **两年平均增长率**：r间≈2×年均（精确r间=(1+年均)²-1）。
- **真题**（2024江西）2022 vs 2020：2022年降38.23%，降幅比上年扩大7.22个百分点 → 2021年降31.01% → r间=(-0.3823)+(-0.3101)+0.3823×0.3101≈-0.574 → 下降57% → 选B。
- **融合（中公/华图"间隔倍数"）**：间隔倍数=(1+r₁)(1+r₂)=1+r间，问倍数直接用。

### 绝技20-三个萝卜三个坑法（混合增长率）★高频
- **识别**：部分+部分=整体（主体混合：出口+进口=进出口；时间混合：1-5月+6月=上半年）。
- **口诀**：①混合后**居中不正中**（min(r₁,r₂)<r混<max(r₁,r₂)），偏向**基期量大**的一方；②线段法：混合之前写两边、混合之后写中间，**距离和量成反比**。
- **真题**（2020深圳）户籍454.70万增长4.6%+非户籍847.97万增长3.6% → r混介于3.6%~4.6%，偏向非户籍(3.6%) → 约3.9% → 选B。
- **融合（十字交叉法）**：与线段法同源，线段法书写更快。花生十三"混合居中"同理。

### 绝技20+-只要思想不滑坡法
- **特征**：问当月/当季增长率 vs 累计增长率。
- **口诀**：当月>累计 ⟺ 当月增速>前期累计增速（大数被拉高 ⟹ 新加的当月贡献大）。反过来：当月<累计 ⟺ 当月增速<前期累计增速。
- **真题**（2025内蒙）2024年3-11月啤酒当期增长率高于累计增长率的有几个月 → 逐月比较当期产量与前期累计平均。

### 绝技21-选项居中代入排除法（年均增长率）
- **公式**：(1+r)ⁿ=现期/基期。
- **操作**：①居中代入选项（代入中间值，判断大了小了，二选一）；②利用幂次方表（见速查表）：1.2³=1.728，1.3³=2.197，1.4³=2.744，1.2⁴≈2.07，1.3⁴≈2.86，1.4⁴≈3.84；11²=121…19²=361。
- **真题**（2024广东）2019-2021县均社会资本年均增长率 → 现期/基期≈? 居中代入21%：1.21³≈1.77 对比实际倍数定位。
- **融合（花生十三"年均增速比较"）**：年份差n相同（都是n年）→ 直接比现期/基期，不用算r！n相同时倍数大→年均增速大。

## 模块六：增长量（绝技22-24）

**审题**：增长/减少+具体单位。**公式**：①增长量=现期-基期；②年均增长量=(现期-基期)/n；③增长量=现期/(1+r)×r。

### 绝技22-百化分套路法★高频
- **两步走**：①百化分 |r|=1/n；②**增长量=现期/(n+1)；减少量=现期/(n-1)**。
- **真题**（2025四川）汽车转让登记1057万辆，增长5.3% → 5.3%≈1/19 → 增长量=1057/20≈53 → "50多万辆" → 选C。
- **真题**（2025黑龙江）烤烟出口量比去年 → 判断增减后，|r|百化分，减少量=现期/(n-1)。
- **融合（花生十三415份数）**：r=1/n时，现期=(n+1)份，增量=1份，一除即出，与百化分套路同源，书写更快。

### 绝技23-口诀比较法（增长量比较）
- **口诀**：①**大大则大**：现期大+增速大 → 增长量大；现期大+降幅大 → 减少量大。②**一大一小百化分**：比较 现期×r/(1+r)，或直接比较 现期/(n+1)。
- **真题**（2024黑龙江）服务业增加值同比增量最多的是：金融业96811×5.6% vs 信息传输47934×9.1% → 一大一小 → 96811/(1+5.6%)×5.6% ≈ 96811/18.9…百化分比较 → 金融业。
- **融合（"大大则大"来自瞪哥，粉笔称"增量比较三步走"）**：先排除明显小的，再对剩下的精比。

### 绝技24-特殊点排除法（图表增量趋势）
- **操作**：①找最高/最低（增量最大的点必须对得上）；②看趋势（先增后减/持续增）。
- **真题**（2025湖北）证券期货私募资管环比增量趋势图 → 先瞪增量为0的位置（横轴上的点），再验证峰值月份。

## 模块七：现期比例（绝技25-29）

**公式**：比重=部分/总体（**占前÷占后**）；平均数=总数/个数（**后÷前**，"平均每"后面的是分母）；倍数=A/B（前÷后）。

### 绝技25-除法技巧巧用瞪眼法
- 比重/平均/倍数题的通用解法：截位直除、错位修正。
- **真题**（2025浙江）货物贸易顺差：出口-进口 → 顺差/进出口 → 拆分+截位。
- **排序题**（2024广东）：多个分数比大小 → 绝技9分数比较口诀。

### 绝技25+-饼状图特殊角度瞪眼法
- **看图**：12点方向起顺时针依次对应材料主体顺序。
- **做题**：①大小关系排除（最大/最小扇形）；②特殊角度对应：90°=25%，180°=50%，270°=75%。
- **真题**（2025天津）东西部固话用户比例 → 东部占比接近50%看是否过180°线。

### 绝技26-中间值估算法
- **特征**：一组数平缓变化，求平均数。
- **绝技**：平均数≈(最大+最小)/2。
- **真题**（2023联考）最接近全国羊肉年平均产量的年份 → (首+尾)/2定位。

### 绝技27-削峰填谷法
- **操作**：①确定基准值（好算的整数）；②找峰找谷，削峰填谷；③平均数=基准值+削峰填谷后/个数。
- **真题**（2024黑龙江）2017-2022交通固定资产年平均投资额 → 基准3.4万亿，逐个削填。

### 绝技28-转化思维法
- **特征**："4月 > 1-3月平均？" ⟺ 4×4月 > 1-4月（乘法转化，免除法）。
- **真题**（2019联考）4月手机产量高于1~3月平均的省市个数 → 4×当月 > 累计。

### 绝技29-以坑治坑法（比例版）
- **双重平均数**：平均的average，问"每人每月" → 除以人数再除以12，注意选项可能只除了一个维度。
- **倍数坑**："多/增长几倍"=是几倍-1。
- **真题**（2022江苏）原油进口量比生产量多几倍：30193/11561-1≈1.6 → 选A。

## 模块八：基期比例（绝技30-32）

**公式**：基期比例=A/B×(1+b)/(1+a)（A、B为现期部分与总体，a、b为对应增速）。

### 绝技30-左算右瞪法★高频
- **操作**：算 A/B（左边精算），瞪 (1+b)/(1+a)（右边估算微调）。
- **真题**（2024山西）2023年1-4月新能源发电占比：609.0/2582.0×(1+12.2%)/(1+16.1%) → 左边≈23.6%，右边≈0.97 → 23.6%×0.966→ 瞪小一点 → 22.8% → 选D。

### 绝技31-除法技巧巧用瞪眼法
- 基期平均数/倍数：截位直除+错位修正。
- **真题**（2024黑龙江）2021铁路投资是民航的倍数 → 分子分母各自化基期再相除，或先算现期倍数再用(1+b)/(1+a)修正。

### 绝技32-特殊公式法
- **适用**：选项差距都很近，且a较小。
- **公式**：基期比例=A/B×[1-(a-b)]（即现期比例减去(1+b)/(1+a)≈1-(a-b)的修正）。
- **真题**（2020河南）2013年工业品物流占比：2697.55/3502.63×[1-(11.4%-7.6%)] → 77%×(1-3.8%)→77%-2.9%≈74.1% → 选B（74.39%）。

## 模块九：两期比例（绝技33-35）

### 绝技33-两步杀口诀法★超高频
- **比较类**（判断比重/平均数升降）：**a>b，比例上升；a<b，比例下降**（a=分子增速，b=分母增速）。
- **计算类**（比重差多少百分点）：①判升降；②**秒最小**：比重差<|a-b| → 直接锁定不超过|a-b|的选项；③需精确时用公式：比重差=A/B×(a-b)/(1+a)。
- **真题**（2025国考）小额批量支付笔数占比变化：a=5.73%，b=0.92% → a>b上升；差=A/B×4.81%/1.0573 < 4.81个百分点 → 结合A/B≈21% → 差≈1个百分点 → "上升不到2个百分点" → 选D。
- **真题**（2025宁夏）自行车出口均价同比：均价=金额/数量，数量增速>金额增速 → 下降。

### 绝技34-逆向思维法
- **特征**：已知比例变化，反推增长率。
- **工具**：①比重差<|a-b|；②比例上升→a>b；比例下降→a<b；③精确：r_a=(比重差/现期比重)×(1+b)+b。
- **真题**（2024江苏）前六大行业占比65.3%比上年提高0.7个百分点，总产值增3.6% → a=(0.7%/65.3%)×1.036+3.6%≈1.07%+3.6%≈4.7% → 选C。

### 绝技35-公式无脑代入法（平均数增长率）★高频
- **公式**：平均数增长率 **r=(a-b)/(1+b)**（a=分子即"总数"增速，b=分母即"个数"增速）。
- **比较类**：重点只看 (a-b)——多个平均数增速排序时，(1+b)几乎不影响相对大小。
- **真题**（2025国考）平均每笔业务金额增速：(12.59%-6.97%)/(1+6.97%)≈5.62%/1.07≈5.25% → 每笔金额上升但值很小 → 上升不到1000元 → 选C。
- **真题**（2025事业编联考）平均每家加计扣除额：a=69.5%（总额），b=25.2%（家数）→ (69.5-25.2)/125.2≈44.2/125.2≈35% → 增长30%以上 → 选D。

## 模块十：综合分析（绝技36）

### 绝技36-排除法
- **操作**：
  1. **先看CD，再看AB**（统计规律：正确答案在CD概率略高，且CD常含更简单判断项）。
  2. **遇难则跳**：现期优于基期（现期只需加减）、比较优于计算（口诀秒杀）、口诀类优先（两期比重口诀等）。
  3. **注意陷阱**：时间范围（1-6月 vs 上半年）、"约/超过/不足"、年均（基期选择）、主体（"其中"嵌套）。
- **真题**（2025四川）"能够推出的是" → D选项"业务用房/房屋面积比值高于上年"：a=4.7% > b=5.5%? 不，用房4.7% < 房屋5.5% → 比值下降 → D错；C选项增量比较用口诀比较法验证。
- **融合**：综合分析每项判断按"题型路由表"逐项路由到对应绝技，优先验证零计算口诀类选项。
